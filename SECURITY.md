# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Report vulnerabilities privately through either of these channels:

- GitHub private security advisories: https://github.com/chamuka-inc/chamuka-design/security/advisories/new
- Email: security@chamuka.ai

Include a description of the issue and steps to reproduce.

We will acknowledge reports and work on a fix before any public disclosure.
