# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/chamuka-inc/chamuka-design/security/advisories/new) on this repository.

If you cannot use advisories, email name@chamuka.ai (placeholder) with a description of the issue and steps to reproduce.

We will acknowledge reports and work on a fix before any public disclosure.
