# Security policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Report vulnerabilities privately through either of:

- [GitHub security advisories](https://github.com/chamuka-inc/chamuka-design/security/advisories/new) on this repository
- Email [security@chamuka.ai](mailto:security@chamuka.ai)

Include a description of the issue and steps to reproduce.

We will acknowledge reports and work on a fix before any public disclosure.
