# `@chamuka/icons`

React components generated from `brand/svg` via SVGR (`src/generate.ts`). Fills stay as authored.

- Pass `title` for an accessible name. Without `title`, the SVG is `aria-hidden`.
- Do not recolour the sun, horizon, or gold bar.
- Diagrams (`donts`, `clear-space`, `min-sizes`) are not components.
- Product chrome icons: Lucide, not this package.
