# Daybreak design system

Daybreak is the brand and UI system for **[Chamuka Labs](https://chamuka.ai), an applied AI lab**. Products such as DrawIt (flagship) and FormIt are sub-brands — outputs of the lab. This Storybook is the UI/UX source for those products. Logo masters, print files, and Python generators live in `/brand`. Digital templates live in `/templates`.

**Audience:** business teams. **Feel:** playful, warm, African-rooted — not toy-like. **“From thoughts to form”** is DrawIt’s line only.

## Packages

| Package | Use |
|---|---|
| `@chamuka/tokens` | DTCG tokens → CSS variables, Tailwind v3 preset, Tailwind v4 `@theme`, TS |
| `@chamuka/ui` | React 19 components (Tailwind + UI SDK) |
| `@chamuka/icons` | Daybreak mark, lockups, product marks |

Consuming apps (DrawIt, FormIt, Play) are Next.js + React 19 + Tailwind v3 or v4 with shadcn-style CSS variables. Import `tokens.css` + `theme.css`, `@source` `@chamuka/ui` (or import the compiled `styles.css` fallback), then wrap with `ThemeProvider`. Interactive components wrap UI SDK; presentational ones are plain Tailwind.

## Quick start

See the repository README for Tailwind v3 and v4 wiring. In JSX:

```tsx
import { ThemeProvider, Button } from "@chamuka/ui";

<ThemeProvider>
  <Button>Save</Button>
</ThemeProvider>
```
