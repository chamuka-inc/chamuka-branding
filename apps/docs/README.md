# `@chamuka/docs`

Storybook 8 for the Daybreak design system. Fonts load through `@fontsource` (Sora, IBM Plex Sans, IBM Plex Mono).

```bash
pnpm --filter @chamuka/docs dev
pnpm build-storybook
```

Stories cover every `@chamuka/ui` component, token swatches, and MDX guidelines for layout, type, colour, motion, accessibility, UX patterns, and voice.
